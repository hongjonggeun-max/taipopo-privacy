일반 문의 및 개인정보 열람·삭제 요청: taipopo.app@gmail.com

TAIPOPO(이하 "앱")는 근태, 근무지, 사진 증빙, 정산 및 리포트 관리를 위한 local-first 앱입니다. 기본 기록은 사용자의 기기에 저장됩니다. 다만 사용자가 선택적으로 Google Drive 백업·복원 또는 외부 공유를 실행하거나, production 앱에서 장애가 발생하는 경우에는 아래에 설명한 외부 서비스 처리가 발생할 수 있습니다.

이 방침은 앱의 기술적 데이터 흐름과 운영 정보를 반영합니다. Google Drive, Google Sign-In, Firebase Crashlytics 및 ML Kit 등 외부 서비스는 각 서비스의 정책과 처리 범위가 함께 적용될 수 있습니다.

2. 처리 목적과 방법

앱은 다음 목적을 위해 필요한 범위에서만 정보를 처리합니다.

  • 출퇴근·근무시간·근무지 기록 및 조회
  • 사진 증빙의 촬영, 편집, 보관, 갤러리 표시 및 리포트 연결
  • 정산 계산, 일일 리포트 및 PDF 생성
  • 사용자가 직접 시작한 로컬 ZIP 또는 Google Drive 백업·복원
  • 사용자가 직접 선택한 사진·PDF·ZIP 등의 외부 공유
  • 오류 진단 및 앱 안정성 개선
  • QR 인식 기능 제공

위치 정보는 사용자가 Android 위치 권한을 허용하고 출퇴근 또는 사진 촬영 기능을 실행하는 경우에만 사용합니다. 위치 정보는 광고 또는 프로파일링 목적으로 사용하지 않습니다.

3. 기기 내 저장과 사진·위치정보

기본 데이터는 Android 앱 전용 저장소와 앱의 로컬 데이터베이스에 저장됩니다. 사진은 원본, 표시용 이미지 및 썸네일 등으로 관리될 수 있고, 사진·리포트·PDF·백업에는 촬영 시각, 위치, 근무지 또는 정산 정보가 연결될 수 있습니다.

이미지 공유용 사본을 만드는 경로에는 메타데이터 제거 처리가 포함될 수 있습니다. 그러나 원본 사진, PDF, ZIP, 백업본 또는 사용자가 선택한 외부 앱·저장소의 사본까지 모든 메타데이터가 제거된다고 보장하지 않습니다. 외부로 공유하기 전에는 포함 정보와 수신 대상을 확인해야 합니다.

4. Google Drive 선택적 백업·복원

Google Drive 백업·복원은 사용자가 해당 기능을 직접 시작할 때에만 실행됩니다. 앱은 Drive API의 appDataFolder 공간을 사용해 앱별 백업을 저장·조회·복원합니다.

  • appDataFolder는 Google이 앱별 데이터를 위해 제공하는 숨김 저장 공간이며, 일반 Google Drive 파일 목록에서 직접 열람하거나 다른 Drive 앱과 공유할 수 없는 특성이 있습니다.
  • 앱은 사용자가 백업 또는 복원을 선택하지 않은 상태에서 근태·사진·정산 데이터를 Google Drive로 업로드하지 않습니다.
  • 백업에는 원본 사진·위치·촬영 시각·기기 메타데이터, 근무지·주소·근태·급여·정산·메모 등 앱 데이터의 전체 또는 일부 사본이 포함될 수 있습니다.
  • 로컬 데이터 초기화, 앱 삭제 또는 Google 연결 해제는 기존 Google Drive 백업을 자동으로 삭제하지 않습니다.
  • 로컬 데이터 초기화와 Google 연결 해제는 Drive 백업 삭제와 별개입니다. 현재 앱 화면에는 Drive 백업을 직접 삭제하는 기능이 없습니다. appDataFolder는 일반 Drive 파일 목록에서 직접 열람·공유할 수 없는 공간이므로, 백업 삭제 또는 삭제 확인이 필요하면 taipopo.app@gmail.com으로 문의할 수 있습니다.
  • 앱의 관리형 retention 처리 외에 사용자 백업에 대한 고정 보유일수 정책은 확정되어 있지 않습니다. 중요한 사본은 사용자가 직접 관리해야 합니다.

백업 ZIP과 Drive 백업에 앱 수준 암호화가 적용되어 있다고 확인되지 않았습니다. 따라서 백업 파일을 암호화된 저장 매체나 신뢰할 수 있는 계정에 보관할 책임은 사용자에게 있습니다.

5. Google Sign-In

Google Sign-In은 선택적 Google Drive 연결과 Drive API 접근 권한 획득을 위해 사용됩니다. 사용자는 Google의 인증·동의 화면에서 요청 범위를 확인하고 연결 여부를 선택할 수 있습니다. 앱은 독립적인 TAIPOPO 사용자 계정을 생성하지 않습니다.

Google 연결 해제는 앱과 Google 계정의 연결을 해제하는 동작이며, Google Drive에 이미 만들어진 백업을 삭제하는 동작이 아닙니다.

6. Firebase Crashlytics

production 앱은 오류·장애 진단을 위해 Firebase Crashlytics를 사용합니다. 앱이 직접 전달하는 오류 경로는 사용자 입력, 파일 경로, 위치, 금액, 계정 식별자가 포함되지 않도록 정제된 오류 코드와 안전한 stack frame을 사용합니다.

Firebase의 공식 안내에 따르면 Crashlytics는 crash stack trace, Crashlytics Installation UUID, Firebase Installation ID, 세션 식별자, 앱 버전, 운영체제 및 기기 관련 정보를 진단 목적으로 처리할 수 있습니다. Firebase는 Crashlytics crash stack trace와 관련 식별자를 90일 보관한 뒤 live 및 backup 시스템에서 제거 절차를 시작한다고 안내합니다.

앱의 로컬 데이터 초기화나 앱 삭제는 이미 Firebase에 전송된 진단 정보를 동일한 범위로 자동 삭제하지 않습니다. 관련 문의 및 삭제 요청은 taipopo.app@gmail.com으로 접수할 수 있으며, 실제 처리 범위와 절차는 Firebase의 기능과 정책에 따릅니다.

7. ML Kit QR 인식

앱의 QR 스캐너는 QR 형식만 인식하도록 구성되어 있습니다. Google ML Kit 공식 안내에 따르면 ML Kit API의 입력 데이터(이미지·영상·텍스트)와 인식 결과는 기기 내에서 처리되며 Google 서버로 전송되지 않습니다.

다만 ML Kit API는 버그 수정, 모델 업데이트, 하드웨어 호환성 확인을 위해 Google 서버와 통신할 수 있고, 앱 내 API 성능·사용량 metrics를 Google로 전송할 수 있습니다. 공식 Android 데이터 고지 문서는 기기·앱 정보, 설치 관련 식별자, 성능 metrics, API 설정·이벤트·오류 코드 등이 진단 및 사용량 분석 목적으로 처리될 수 있음을 안내합니다.

8. 외부 공유·PDF·ZIP

사진, PDF, ZIP, 리포트는 사용자가 공유 또는 저장 작업을 직접 선택한 경우에만 Android 공유 기능이나 선택한 외부 앱·저장소로 전달됩니다. 전달된 사본의 보유·삭제·접근 권한은 수신 앱, 저장소 및 사용자의 설정에 따라 달라집니다.

TAIPOPO의 로컬 데이터 초기화는 사용자가 이미 외부로 공유·저장한 파일을 삭제하지 않습니다. 사용자는 해당 파일이 저장된 외부 앱·클라우드·기기에서 직접 삭제해야 합니다.

9. 보유·삭제 및 사용자의 권리

사용자는 앱에서 자신의 로컬 기록을 조회·수정·삭제하고 Android 설정에서 권한을 변경하거나 철회할 수 있습니다.

  • 사진은 삭제 후 휴지통에서 복원하거나 영구 삭제할 수 있습니다. 사진 휴지통은 최대 30일 보관 후 정리될 수 있습니다.
  • 메모, 근무지, 정산, 리포트 등은 각 기능의 삭제·휴지통·영구 삭제 기능 또는 전체 데이터 초기화를 통해 관리할 수 있습니다. 사진 외 항목의 고정 자동 보유기간은 확정되어 있지 않습니다.
  • 전체 데이터 초기화는 기기 내 앱 설정, 로컬 데이터베이스, 사진, PDF, 리포트, 내보내기 및 로컬 백업 관련 데이터를 삭제합니다.
  • Google Drive 백업, 외부 공유·다운로드본 및 Firebase Crashlytics에 이미 전송된 진단 정보는 위 로컬 삭제 범위와 별개입니다.
  • 개인정보 열람·삭제 요청이나 관련 문의는 taipopo.app@gmail.com으로 보낼 수 있습니다.
